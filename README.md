# Megbli Labs — Portfolio

## Deploy on GitHub Pages (free)
1. Create a public GitHub repo named `megbli-labs`
2. Upload all files (index.html, project.html, css/, js/)
3. Repo → Settings → Pages → Source: "Deploy from a branch" → main / (root) → Save
4. Site will be live at: https://<username>.github.io/megbli-labs/
5. Later (optional): buy megblilabs.com (~10$/yr), add it in Pages settings + CNAME file
